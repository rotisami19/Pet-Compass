# Pet Compass Mod

A simple NeoForge 1.21.1 mod that adds a **Pet Compass** to help you find your lost companions.

## Features

-   **Pet Compass Item**: A beautiful, custom-designed compass.
-   **Tracking**: Right-click on any mob (Pet, Villager, etc.) to link the compass to their current location.
-   **Navigation**: The compass needle will point to the linked location, working across dimensions.
-   **Persistance**: The linked location is saved on the compass item.

## How to use

1.  Craft or find the **Pet Compass** in the Creative "Tools & Utilities" tab.
2.  **Right-click** on your pet.
3.  The compass will glow and point to that spot.
4.  If you get lost, follow the needle!

## Installation

1.  Place the `.jar` file in your `mods` folder.
2.  Make sure you have NeoForge 21.1.x installed.
